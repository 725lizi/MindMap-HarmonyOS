# 更新日志（Changelog）

## 1.0.0 — 2026-09-21

首个正式版本，发布至 ohpm 中心仓。

### 新增

- 原生 ArkUI 思维导图组件 `MindMapView`：传入标准树节点 JSON 即可渲染，零 WebView 依赖。
- 自研后序轮廓（tidier）紧凑树形布局算法，复杂度 O(n·深度)，不对称树也能紧凑不重叠。
- 手势交互：双指缩放、单指平移、双击在「放大 2x / 回到整树适配」间切换；首次进入自动整树适配居中。
- 编辑能力（示例演示）：回车加同级、Tab 加子级、空输入 Delete 删除；组件支持可选 `selectedId` 选中描边。
- JSON 序列化 / 反序列化：`JsonSerializer` 支持标准信封与裸根节点两种输入，非法输入抛出可识别错误。
- 图片导出：`ImageExporter.saveToGallery` 一键保存 PNG 到系统相册，含权限申请与三态处理。
- 主题与连线样式可配置：节点配色、字号、曲线 / 折线连线。
- 74 个本地单元测试覆盖数据模型、布局算法（含黄金坐标与随机树不变量审计）、视口状态机、整树适配、序列化、编辑控制与主题。

### 落地案例

- 已在个人项目 FocusTimer（HarmonyOS 专注计时 + DeepSeek AI 应用）中实际落地，渲染由大模型生成的效率复盘脑图，离线时降级为本地规则树。
